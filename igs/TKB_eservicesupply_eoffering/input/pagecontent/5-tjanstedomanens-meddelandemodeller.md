# 5 Tjänstedomänens meddelandemodeller

## Övergripande meddelandestruktur

Tjänstedomänen eservicesupply:eoffering definierar följande meddelandetyper.

## Namnrymd för meddelandemodeller

| Schema | Namnrymd |
|--------|----------|
| Domänkomponenter | `urn:riv:eservicesupply:eoffering:1` |
| Interaktionsschema | `urn:riv:eservicesupply:eoffering:GetAvailableEServicesResponder:1` |

## Schemafiler

| Fil | Beskrivning |
|-----|-------------|
| `eservicesupply_eoffering_1.0.xsd` | Gemensamma domänkomponenter (eServiceType, restrictionType, healthcareFacilityInfoType, eServiceAreaCodeType) |
| `GetAvailableEServicesResponder_1.0.xsd` | Interaktionsschema för GetAvailableEServices |
| `itintegration_registry_1.0.xsd` | Engagemangsindex-komponenter (delad) |
| `ws-addressing-1.0.xsd` | WS-Addressing (delad infrastrukturreferens) |
