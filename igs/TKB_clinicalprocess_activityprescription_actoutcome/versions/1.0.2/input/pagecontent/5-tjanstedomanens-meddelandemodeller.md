## Tjänstedomänens meddelandemodeller

*SAKNAS I KÄLLDOKUMENT — TKB 1.0 har inget eget kapitel om tjänstedomänens meddelandemodeller.* Meddelandemodellen (MIM) för domänens enda tjänstekontrakt beskrivs i kontraktets eget avsnitt, se [MIM för GetVaccinationHistory](7-tjanstekontrakt.html#mim). Kapitel 4, avsnittet [Tjänstekontraktens design](3-tjanstedomanens-arkitektur.html), beskriver den gemensamma dokumentstrukturen (PatientSummaryHeader och kontraktsspecifik Body).
