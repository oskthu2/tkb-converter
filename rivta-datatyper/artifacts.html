This page provides a list of the FHIR artifacts defined as part of this implementation guide.

Structures: Logical Models

These define data models that represent the domain covered by this implementation guide in more business-friendly terms than the underlying FHIR resources.

ActorType

Medarbetare i vård och omsorg (xs:complexType.)
CVType

Referens till ett begrepp i ett externt kodverk. (xs:complexType.)
DatePeriodType

Datumintervall med minst ett start- eller slutdatum. (xs:complexType.)
HealthcareProfessionalType

Vård- och omsorgspersonal samt organisatorisk tillhörighet. (xs:complexType.)
IIType

Unik identifierare för ett objekt eller en entitet. (xs:complexType.)
LegalAuthenticatorType

Signatur och uppgifter om signerande person. (xs:complexType.)
MultimediaType

Multimediaobjekt som binärdata eller extern referens. (xs:complexType.)
OrgUnitType

Identitets-, kontakt- och adressuppgifter för en organisationsenhet. (xs:complexType.)
PQIntervalType

Intervall av mätbara värden med enhet. (xs:complexType.)
PQType

Mätbart värde med enhet. (xs:complexType.)
PartialDateType

Datum med variabel noggrannhet. (xs:complexType.)
PersonIdType

Identifierare för en person och typ av identifierare. (xs:complexType.)
ResultType

Resultatkod och valfri text för logiska fel. (xs:complexType.)
TimePeriodType

Tidsintervall med minst en start- eller sluttidpunkt. (xs:complexType.)

Structures: Data Type Profiles

These define constraints on FHIR data types for systems conforming to this implementation guide.

DateType

Datum på formatet YYYYMMDD utan tidszon. (xs:simpleType, restriktion av xs:string.)
DecimalPrimitiveType

Decimaltal som bevarar signifikanta avslutande nollor. (xs:simpleType, restriktion av xs:string.)
HSAIdType

HSA-id: identifierare i HSA-katalogen för en person, organisation, enhet eller funktion. (xs:simpleType, restriktion av xs:string.)
PartialDateValueType

Datumvärde på formatet YYYY, YYYYMM eller YYYYMMDD. (xs:simpleType, restriktion av xs:string.)
TimeStampType

Tidpunkt på formatet YYYYMMDDhhmmss utan tidszon. (xs:simpleType, restriktion av xs:string.)
UUIDType

Universellt unik identifierare (UUID/GUID): 32 hexadecimala tecken, med eller utan bindestreck i mönstret 8-4-4-4-12. (xs:simpleType, restriktion av xs:string.)
