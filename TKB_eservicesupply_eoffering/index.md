# eservicesupply: eoffering

## Översikt

FHIR Implementation Guide för tjänstedomänen **eservicesupply: eoffering** version 1.0. Genererad från Ineras Tjänstekontraktsbeskrivning (TKB) v0.3 (2011-04-18).
