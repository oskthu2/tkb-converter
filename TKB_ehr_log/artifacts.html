Structures: Logical Models

These define data models that represent the domain covered by this implementation guide in more business-friendly terms than the underlying FHIR resources.

GetAccessLogsForPatient

Logisk modell för tjänstekontraktet GetAccessLogsForPatient (RIV-TA urn:riv:ehr:log:querying:GetAccessLogsForPatientResponder:1). Representerar responsens informationsstruktur (log.querying:AccessLogsResult). Returnerar lista för angiven patient med vilka vårdaktörer som har haft åtkomst till information, inklusive tidpunkt, syfte och resurstyp. Stödjer aggregering — queuedReportId får inte användas vid aggregerande anrop.
GetAccessLogsForPatient — Request

Logisk modell för requestparametrar i GetAccessLogsForPatient. Obs: queuedReportId ska INTE användas när aggregerande tjänst anropas.
GetInfoLogsForCareProvider

Logisk modell för tjänstekontraktet GetInfoLogsForCareProvider (RIV-TA urn:riv:ehr:log:querying:GetInfoLogsForCareProviderResponder:1). Representerar responsens informationsstruktur (log.querying:InfoLogsResult). Returnerar lista för angiven informationsägande vårdgivare med vilka externa vårdgivare som har haft åtkomst till vårdgivarens information.
GetInfoLogsForCareProvider — Request

Logisk modell för requestparametrar i GetInfoLogsForCareProvider.
GetInfoLogsForPatient

Logisk modell för tjänstekontraktet GetInfoLogsForPatient (RIV-TA urn:riv:ehr:log:querying:GetInfoLogsForPatientResponder:1). Representerar responsens informationsstruktur (log.querying:InfoLogsResult). Returnerar lista för angiven informationsägande vårdgivare och patient med vilka externa vårdgivare som haft åtkomst till information.
GetInfoLogsForPatient — Request

Logisk modell för requestparametrar i GetInfoLogsForPatient.

GetLogsForCareProvider — Request

GetLogsForPatient

GetLogsForPatient — Request

StoreLog

Logisk modell för tjänstekontraktet StoreLog (RIV-TA urn:riv:ehr:log:store:StoreLogResponder:1). Representerar responsens informationsstruktur (log.store:Result). Tjänsten sparar en eller flera loggposter i loggtjänsten för att möjliggöra uppföljning enligt PDL.
StoreLog — Request

Logisk modell för requestparametrar i StoreLog (RIV-TA urn:riv:ehr:log:store:StoreLogResponder:1). Innehåller en samling loggposter (log:Log) som ska lagras.
