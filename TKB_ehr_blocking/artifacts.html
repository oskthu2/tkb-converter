Terminology: Code Systems

These define new code systems used by systems conforming to this implementation guide.

BlockType

Typ av spärr enligt urn:riv:ehr:blocking:2. Anger om spärren gäller inom en vårdenhet (inre) eller inom hela vårdgivaren (yttre).
ResultCode

Svarskoder för spärrtjänsternas operationer enligt urn:riv:ehr:blocking:2. Alla svarskoder förutom OK och INFO betyder att åtgärden inte genomfördes.

Orsak till tillfällig hävning av spärr enligt urn:riv:ehr:blocking:2.
