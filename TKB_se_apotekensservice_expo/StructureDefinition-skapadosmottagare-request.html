Obligations
skapadosmottagare-request C 0..* Base SkapaDosmottagare — Request
Instances of this type can be the target of a Reference
Constraints: skapadosmottagare-request-adress-when-d
adress 0..1 string Adress till dosmottagare. Obligatorisk om typ = 'D'.
apoteksIdDosmottagare 0..1 string Apoteks-id för dosmottagare om dosmottagare är av typen apotek.
apoteksIdDosproducent 1..1 string Apoteks-id för dosproducent som dosmottagaren ska registreras på.
arbetsplatskod 0..1 string Arbetsplatskod till dosmottagare. Är aktuellt om dosmottagare t ex är en distriktsläkarmottagning.
avdelning 0..1 string Avdelning inom dosmottagare.
dosmottagarId 1..1 string Dosmottagarens identitet, dosproducentens identitet för dosmottagaren t ex kundnummer, GLN-kod. Unikt inom dosapoteket.
kommunkod 0..1 string Kommunkod till vilken dosmottagarens tillhör. Kod enligt SCB.
lanskod 0..1 string Länskod till vilken dosmottagaren tillhör. Kod enligt SCB.
mottagarnamn 1..1 string Namn på dosmottagare.
postnummer 0..1 string Postnummer till dosmottagare.
postort 0..1 string Arbetsplatsort till dosmottagare. Obligatorisk om typ = 'D'.
typ 1..1 string typ

Documentation for this format

Constraints

Id Grade Path(s) Description Expression
skapadosmottagare-request-adress-when-d error skapadosmottagare-request adress och postort ska anges när typ = 'D' (direktleverans). typ = 'D' implies (adress.exists() and postort.exists())
